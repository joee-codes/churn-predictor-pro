# 🚀 ChurnLens-Pro

An AI-powered Customer Churn Prediction Platform built using Machine Learning and Streamlit.

## 📌 Project Overview

ChurnLens-Pro helps businesses identify customers likely to churn by analyzing customer data and generating intelligent predictions with actionable insights.

## ✨ Features

- Single Customer Prediction
- Bulk Customer Prediction
- Analytics Dashboard
- Customer Segmentation
- Model Insights
- Explainability
- AI Chat Assistant
- Prediction History

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Plotly
- SQLite

## 📊 Model Performance

| Metric | Score |
|----------|----------|
| ROC-AUC | 78.5% |
| Model | Random Forest |

## 🚀 Installation

```bash
git clone https://github.com/joee-codes/ChurnLens-Pro.git
cd ChurnLens-Pro
pip install -r requirements.txt
streamlit run app.py
```
